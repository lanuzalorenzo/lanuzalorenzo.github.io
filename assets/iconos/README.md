# Icono del repositorio

Un único SVG, `web.svg`, usado en la cabecera del README y como icono de la carpeta del repositorio.

- Glifo: marca LL del sitio, la misma del favicon (primera L blanca, segunda cian).
- Formato: [identidad visual del workspace](https://github.com/lanuzalorenzo/lanuzalorenzo.github.io/blob/main/docs/identidad-visual.md) — 64×64, `rx=16`, fondo navy con degradado.

El acceso del escritorio a la web publicada usa la misma marca con un distintivo de globo cian, así que «repo de la web» y «web publicada» se reconocen como pareja sin compartir nombre de archivo: `web.svg` y `web-enlace.svg`.

## Origen y licencia

La marca LL es propia: está compuesta con dos trazos rectangulares y no procede de ninguna biblioteca de iconos. El favicon del sitio es la referencia.
