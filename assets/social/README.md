# Piezas de redes

Avatar con la marca LL. La geometría de la marca está en [`assets/marca/README.md`](../marca/README.md).

## Avatar

`avatar-400.png` es la pieza para GitHub y LinkedIn, 400×400 y recortada en primer plano.

Es foto, no marca, y es una decisión explícita: en LinkedIn y GitHub el avatar identifica a una persona, y a 32 px una cara se lee como alguien mientras que un símbolo se lee como una empresa. La marca no se pierde: sigue en el favicon y en los iconos.

El fondo ocupa el cuadrado completo y no lleva borde: GitHub y LinkedIn recortan el avatar en círculo y un borde en el canto se perdería. La cara se queda dentro del círculo inscrito.
