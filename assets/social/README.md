# Piezas de redes

Avatar con la marca LL. La geometría de la marca está en [`assets/marca/README.md`](../marca/README.md).

## Avatar

`avatar-400.png` es la pieza para GitHub y LinkedIn, 400×400. Es la marca, no una foto: la familia de iconos (repo, favicon, OG y carpetas del PC) usa la misma marca; el retrato sigue en la web y en el perfil.

`avatar-400.svg` es la fuente; el PNG se genera desde él. El fondo ocupa el cuadrado completo y no lleva borde: GitHub y LinkedIn recortan el avatar en círculo y un borde en el canto se perdería. La marca se queda dentro del círculo inscrito; a 32 px se mantiene la doble L y el punto.

## Portada de LinkedIn

Sin pieza en este repositorio. La portada se diseña aparte y se sube desde el archivo final, sin publicarla en la web.
